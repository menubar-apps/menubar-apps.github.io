Copilot Stats is a native macOS menu bar app that helps you keep an eye on GitHub Copilot premium request costs.

# Features

- View Copilot usage costs in dollars
- Browse usage by month
- See daily costs across the full month
- Launch automatically at login
- Securely store your GitHub token in the macOS Keychain

# Installation

Download the latest version from [GitHub Releases](https://github.com/menubar-apps/copilot-stats/releases).

You can also explore the source code and report issues on [GitHub](https://github.com/menubar-apps/copilot-stats).
